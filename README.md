## 🚀 Installationsguide

Følg disse trin for at køre projektet lokalt på din maskine.

### Forudsætninger

- [Node.js](https://nodejs.org/) (version 18 eller nyere anbefales)
- npm (installeret automatisk sammen med Node.js)

### 1. Klon repositoriet

```bash
git clone [https://github.com/Thomsen716/DDU-Web.git](https://github.com/Thomsen716/DDU-Web.git)

cd DDU-Web

npm install

npm run dev

Når serveren kører, kan du åbne http://localhost:5173 (eller den port, terminalen anviser) i din browser.
```
